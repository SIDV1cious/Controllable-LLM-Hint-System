# 数据库迁移说明

本目录记录系统表结构的增量变更，便于部署、答辩复现和后续维护。

## 执行顺序

1. 先执行 `docs/database_schema.sql` 初始化基础表。
2. 再按文件名前缀顺序执行 `docs/migrations/*.sql`。
3. 已经部署过的数据库不建议重复手工执行同一迁移；如果需要重跑，请先确认字段或索引是否已存在。

## 运行时兼容

为了兼容早期部署环境，系统启动后仍会通过 `ensure_leakage_observability_columns()` 尝试补齐智能辅导实验分析字段。
这只是兜底机制，正式部署和论文复现建议以本目录迁移脚本为准。
